# Pashuraksha

Pashuraksha is a web application featuring a Next.js 16 frontend and an Express.js + Prisma backend.

## 📖 Quick Start & Onboarding

For detailed instructions on installation, database setup, compiling, and running the application for new team members, please refer to the **[SETUP.md](file:///c:/Users/gnr22/pashuraksha/SETUP.md)** guide.

### Quick Commands

#### 1. Development Setup
```bash
# Terminal 1 - Backend
cd backend
npm install
npm run prisma:generate
npm run dev

# Terminal 2 - Frontend
cd frontend
npm install
npm run dev
```

#### 2. Build / Compile
```bash
# Build Backend
cd backend && npm run build

# Build Frontend
cd frontend && npm run build
```

For full setup documentation, environment configuration, and Prisma commands, see **[SETUP.md](file:///c:/Users/gnr22/pashuraksha/SETUP.md)**.
